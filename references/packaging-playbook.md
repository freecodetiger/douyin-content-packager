# 五平台高传播文案

## 统一命题，平台重写

先从完整字幕中确定一个可被正文兑现的传播命题，再为五个平台分别重写。优先选择具体产品或事件、明确结果、真实收益、强冲突、反常识、数字证据或人物处境；主题概括只作兜底。

五个平台共享事实，不共享同一套句子。每个平台的三个标题应分别承担不同点击动机，例如 SEO/信息完整、痛点/共鸣、反常识/结论；首选理由必须指出它对应字幕中的哪项事实与该平台用户的哪种动机。

标题可以高能量、口语化和有悬念，正文必须兑现。财经、医疗、法律、政治与科技事实逐项核对主体、数字、因果、时态、范围和不确定性。避免正文无法支撑的“震惊、逆天、闭眼冲、必赚、百分百”等承诺。

## 可选品牌信息

频道名和个人网站只来自用户明确提供的值：

- 有频道名：自然加入各平台标签；适合时可在 YouTube 标题或正文中出现，但不能为了塞品牌破坏标题可读性。
- 有网站：在每个平台正文的资源、延伸阅读或结尾语境中自然加入完整链接。
- 没有相应值：删除整句和整项，不写“待补充”，不使用 `{频道名}`、`{个人网站链接}` 或任何等价占位符。

## YouTube

输出三个标题、一个首选与理由、描述、时间戳和标签。

- 标题不超过 100 字符，通常将搜索关键词前置；可用 `|` 分隔主题、收益、受众或年份。优先控制在移动端不易截断的长度，不为 SEO 堆词。
- 描述 120–5000 个非空白字符：开头承接标题，中段讲清视频解决的问题和具体发现，结尾可提出一个真实互动问题。
- 时间戳必须来自字幕顺序，格式为 `MM:SS 模块` 或 `HH:MM:SS 模块`；覆盖主要内容转折，不虚构视频不存在的章节。
- 标签 5–30 个，总长度不超过 500 字符，组合核心主题、长尾检索词、受众与使用场景。

## B站

输出三个标题、一个首选与理由、简介、九个标签和粉丝动态。

- 标题不超过 25 字，口语化；内容属性准确时可使用 `【教程】`、`【测评】`、`【干货】`、`【体验】`、`【科普】` 或 `【避坑】`，可用全角 `｜` 分隔。
- 简介 80–1000 个非空白字符：交代问题、核心观点和观看收益；可自然加入点赞、投币、收藏或评论引导，不写机械口号。
- 标签恰好九个，不带 `#`，Markdown 中用顿号分隔。
- 粉丝动态 20–233 个非空白字符：像一条独立预告，给出矛盾或收益，并邀请真实讨论；不要复制简介首段。

## 小红书

输出三个标题、一个首选与理由、正文和标签。

- 标题不超过 20 字，短、具体、有情绪或场景感；可使用恰当 emoji，使用 `|` 或 `｜` 建立停顿，不使用中英文感叹号。
- 三个标题可分别采用痛点共鸣、反常识疑问、结果/收藏价值，不做同义改写。
- 正文 300–500 个非空白字符：第一人称和短段落优先，先写处境或误区，再给出关键发现、可执行要点和互动问题；emoji 只服务节奏。
- 标签 5–10 个，均带 `#`，组合大领域、精准主题、目标人群和使用场景。

## 抖音

输出三个标题、一个首选与理由、简介和话题标签。

- 标题不超过 30 字，前半句尽快出现痛点、冲突、结论或明确收益；适合口播开场，不写过长背景。
- 三个标题优先覆盖好奇/反常识、共鸣/痛点、实用/直接结论。
- 简介 20–250 个非空白字符，补足标题没有说完的信息，不照抄标题；用一两句说清内容价值，可自然邀请评论。
- 标签 3–5 个，均带 `#`，精准优先，不使用 `#热门`、`#上热门` 凑数。

## 视频号

输出短标题、标题＋描述和标签。

- 短标题 1–16 字符，直接陈述主题或价值，不使用 emoji 和生硬网络黑话。
- 标题＋描述合并为 60–800 个非空白字符，语气可信、清楚、略正式；先交代问题，再给出观点和观看价值。
- 标签 3–10 个，均带 `#`，以主题、行业和人群为主。

## Markdown 成品边界

成品只承载可发布文案与必要的内容定位，固定包含：

1. 视频内容定位；
2. YouTube 标题、首选理由、描述、时间戳、标签；
3. B站标题、首选理由、简介、九个标签、粉丝动态；
4. 小红书标题、首选理由、正文、标签；
5. 抖音标题、首选理由、简介、标签；
6. 视频号短标题、标题＋描述、标签。

不加入发布时间建议、Newsletter、个人网站同步检查、发布数据追踪、下次更新或下期主题。封面 A/B/C 方案在 Markdown 写盘后于对话中展示，由生成门禁继续控制。
