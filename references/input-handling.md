# 输入与质量门禁

## 字幕/文字稿文件

支持以下常见输入：

- 时间轴字幕：`.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc`；
- 纯文字稿：`.txt`、`.md`；
- 结构化字幕导出：包含可识别字幕文本或 cue 的 `.json`。

绝对路径直接使用；相对路径以当前工作区为基准解析。对话内粘贴文字只能补充背景，不能替代必需文件。文件必须存在、可读、非空，并覆盖到能够判断主题、论点与结论的程度。格式不在列表中时，只有当前环境能够可靠提取完整文字才可接受；否则要求用户转换为上述格式。

### 语义还原

把字幕看作带时间顺序的完整口语：

1. 识别并在内容分析中忽略序号、时间码和 ASS 样式控制符；
2. 保持原始顺序，合并跨 cue 的句子、中英文术语和连续列举；
3. 折叠相邻 ASR 重复、无意义停顿与口头填充词；
4. 保留否定、限定条件、反问、引用和立场变化；
5. 用上下文理解明显同音字与标点缺失，事实名称不确定时保持原样并降低结论强度；
6. 区分作者观点、引用观点、举例与被作者反驳的说法。

只在工作记忆中清洗，不修改或重写输入文件。

## 主人公自拍照

接受当前图像查看和生成能力能够读取的常见图片文件，例如 `.jpg`、`.jpeg`、`.png`、`.webp`、`.heic`、`.heif`、`.avif`。格式列入清单不等于自动通过；必须实际打开检查。当前工具无法读取时，要求转换为 JPG 或 PNG。

最低门槛是一张清晰正面照片：

- 完整看见眼睛、鼻子、嘴和主要脸部轮廓；
- 对焦清楚、光线足够，没有重度滤镜或过度磨皮；
- 墨镜、口罩、手或头发没有遮挡主要五官；
- 分辨率足以作为身份参考，优先长边不低于 1024 像素；
- 照片中的主人公就是视频主人公。

推荐再提供 1–2 张不同角度、表情或手势照片。额外照片不能弥补正面照缺失。

检查后为图片标注角色：`正面身份主参考`、`侧面参考`、`表情参考` 或 `手势/姿态参考`。封面生成时保持身份和脸型，只按选定方案调整表情、手势、服装光线和构图。

## 门禁失败回复

一次性列出所有缺失或不合格项，并说明最短修复方法。门禁失败时不输出内容分析、标题、简介、标签或封面方案。
