# 高信息密度人物封面系统

## 固定风格基准

视觉参考图位于 `../assets/creator-cover-style-reference.png`。设计方案前查看它；生成阶段也可将它作为“版式与风格参考图”传入。参考图中的博主人脸、衣着和具体作品不是身份来源，不复制到成图。用户自拍照才是唯一人物身份来源。

## 可复用视觉语法

目标不是极简海报，而是高完成度的中文科技/知识博主封面：

1. 主人公是固定品牌锚点，占画面约 25%–40%，清晰抠像感，带白色或高亮轮廓边缘。
2. 背景使用与主题直接相关的产品界面、品牌符号、设备、人物或真实场景，并用暗化、虚化和局部光线让文字与脸部前置。
3. 文字分为两到三个语义块：产品/事件名、核心收益或冲突、可选限定词。总量通常 8–18 个汉字或等量中英文。
4. 字体采用粗黑、紧凑、缩略图可读的无衬线风格。白色是基础色，黄色、青色、荧光绿或紫红色强调关键词；单张通常使用 2–4 个文字颜色。
5. 人物使用主动但可信的表情和手势：指向、展示、托举、轻度惊讶、疑问、开心或自信。人物动作应把视线导向标题或产品。
6. 使用前中后景建立层次：环境背景、主题对象或 UI 卡片、人物和文字。允许有信息密度，但每个元素都服务同一主题。
7. 整体明亮重点落在脸、主标题和核心产品，四周可压暗；避免大面积空白和过度克制。

## 三种方案骨架

每次根据内容产生三个有实质差异的方案：

- A 产品/事件主视觉：巨型产品名或品牌符号 + 主人公 + 一个强结论，适合工具、AI、产品体验。
- B 对立与问题：两个结果、观点或对象形成左右/前后冲突，主人公居中或作为裁判，适合测评、观点和反常识。
- C 场景与收益：具体生活/工作场景 + 主人公演示 + 收益词，适合教程、职业、成长和商业故事。

每套方案必须写明：封面文字的语义分块、人物表情与手势、背景场景、主题元素、强调色、信息层级、3:4 布局、16:9 布局及有效原因。

## 双比例独立构图

两张图共享人物、文字、背景主题、核心对象和配色，但重新排版：

### 3:4 竖版

- 主人公优先放在下半部或中下区域，脸部避免被平台 UI 遮挡；
- 主标题占据上半部，允许 2–4 行短语义块；
- 产品/UI/场景作为中景包围人物，保留上下安全边距；
- 文字不能简单沿用横版字号压缩。

### 16:9 横版

- 常用左右分栏、三角构图或顶栏标题；
- 人物占一侧或下方前景，另一侧放产品、冲突对象或大标题；
- 预留右下角时长标记区域，不把核心字放在最底部；
- 充分使用横向场景，不把竖版放在中央后补背景。

## 方案选择门禁

输出 A/B/C 后停止。用户可以选择、混合或要求修改。只有用户明确选定并确认生成，才进入图像工具。修改后的方案必须再次展示最终封面文字与双比例布局，再按用户明确意图决定是否已经获得生成许可。

## 生成输入角色

调用 built-in 图像生成时，逐一标记输入图像角色：

- `Image 1`：用户正面自拍，身份主参考；锁定脸型、五官和辨识度。
- `Image 2–3`：可选的侧面、表情或手势参考；只补充对应信息。
- `Style reference`：`assets/creator-cover-style-reference.png`，只参考信息密度、人物描边、粗体排版、配色、主题场景和层次；严禁复制其中人物身份。

为两个比例分别形成一份生成规格；双比例 Pipeline 预检通过后，在同一批次并发各调用一次 built-in 图像生成：

```text
Use case: ads-marketing
Asset type: 3:4 或 16:9 中文自媒体视频封面
Primary request: 选定方案的传播命题和视觉冲突
Input images: 明确列出身份主参考、辅助自拍和风格参考
Subject: 用户本人及主题产品/场景
Scene/backdrop: 与字幕内容直接相关的具体环境
Style/medium: 高完成度中文科技/知识博主封面，人物抠像白边，高信息密度粗体排版
Composition/framing: 当前比例的独立布局和安全区域
Color palette: 深色环境底 + 白字 + 2–3 个高饱和强调色
Text (verbatim): 按语义块逐字列出全部封面文字
Constraints: 保持用户身份；缩略图可读；文字准确；主题对象准确
Avoid: 复制风格参考中的人脸；无关装饰；乱码；水印；机械裁切另一比例
```

## QA 与额度控制

两个并发调用都结束后逐张查看原图，检查身份、准确文字、主题元素、人物描边、色彩重点、层次和小尺寸可读性。默认批准额度只覆盖两张首轮成图。任一调用失败，或文字、身份、构图明显失败时报告具体问题，询问用户是否授权针对失败比例再生成；不得自动补发或重试。
